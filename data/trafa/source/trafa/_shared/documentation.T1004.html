API-dokumentation

Här hittar du mer information den data som finns tillgänglig via vårt API. Våra statistikprodukter är olika och innehåller olika variabler och data, beroende på produkt. Därför finns ingen gemensamt sätt att hämta ut alla data, oavsett produkt. API-dokumentationen hjälper dig att se vilken typ av data som kan hämta från respektive produkt.

Välj först statistikprodukt som du vill hämta data från i rullisten. Då hittar du de variabler och namn som är aktuella för just den produkten. Där finns också information om vanliga anrop som du kan använda för att göra ett anrop till vårt API.

Vill du hålla dig uppdaterad om förändringar i vår dokumentation?
Skriv upp dig på vår lista, så får du utskick vid förändringar.
